# Codex em Acao - Demo Local

Demo estatica e interativa em portugues mostrando exemplos aplicados de uso do Codex:

- planejamento de execucao;
- geracao de texto;
- revisao de codigo;
- automacoes simuladas;
- dashboard visual com indicadores.

## Como abrir localmente

Abra o arquivo `index.html` no navegador.

## Como hospedar

Como o projeto usa apenas HTML, CSS e JavaScript, ele pode ser publicado em GitHub Pages, Netlify, Vercel ou qualquer hospedagem estatica.
